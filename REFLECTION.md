# Reflection

## What assumptions did you make?

I assumed the portal data would be clean. I should have planned for missing or inconsistent records.

## Which part was most difficult?

Finding the balance between a useful dashboard and one that felt overdone.

## What would you improve with another day?

I’d make the dashboard more practical for day-to-day operations.

## What mistake did you make?

I loaded all the data at once, which made the dashboard slower to load.

## What would you criticise in your own submission?

I’d remind myself that less can be more. Adding more doesn’t always make it better.
